# 프로젝트 지식

이 디렉터리는 현재 유효한 프로젝트 지식의 탐색 진입점이다. 문서·코드 관계는 [`../ai/registry/documents.toml`](../ai/registry/documents.toml)에서 관리한다.

- [`INDEX.md`](INDEX.md): 문서 ID, 권한, 관련 코드 경로의 생성 인덱스
- [`../ai/knowledge-operations.md`](../ai/knowledge-operations.md): 근거 수집, 작업 이력, 개선 권한

지속되는 사실·계약·운영 절차가 아니면 새 정본 문서를 만들지 않고 [`../history/`](../history/) 작업 이력에 기록한다.
